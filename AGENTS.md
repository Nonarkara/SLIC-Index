# AGENTS.md

> **Read [CLAUDE.md](CLAUDE.md) § "Anti-Slop Design Law" before any design or frontend work, and [ANTI-SLOP.md](ANTI-SLOP.md) for the prose source of truth.** These are Dr Non's hard rules against AI design slop: empty space is a decision, subtract before you add, the map comes first, and the page is a sequence of attention ordered by importance — not by habit.

They are **machine-enforced**, not a matter of good intentions. `npm run verify:release` fails the build on a violation, and the gate list is in CLAUDE.md. **If a gate fires, fix the design — do not edit the gate.** A gate that gets edited to go green is worse than no gate: it teaches people to route around it.

**Spatial hallucination is also slop.** An interface that invents a reason for things to occupy space — instead of arranging them around how people read, choose and act — fails the same test, whether or not it looks composed. Ask of every element: *why is this here, why this size, and why this far from that?* "The grid put it there" is not an answer. `npm run check:spatial` measures this in a real browser across 15 routes × 3 widths: dead bands, orphan rows, accidental wrapping, clipped text, scattered actions, false hierarchy, and the cost of the first decision. See CLAUDE.md § "Spatial hallucination".

**An index that answers with citations has to describe the bytes it was built from.** The knowledge rack is the site's question box over the methodology, and it cites the documents it was built from. `npm run check:knowledge-rack` proves that every hash in the manifest matches the source on disk, every source is indexed, and the published catalog is the same bytes as the built one. `npm run check:contacts` keeps personal contact details out of the corpus entirely. To change the corpus, drop the document into `knowledge-rack/inbox/` and run `python3 scripts/build_knowledge_rack.py` — never hand-edit the manifest. See CLAUDE.md § "The knowledge rack".

**The author's name is one fact: `Dr Non Arkaraprasertkul` / `ดร.นน อัครประเสริฐกุล`.** The site had been publishing three different renderings, across the footer, the awards page, the history timeline, the citation guidance, the CSV and the PDF metadata. `npm run check:author-name` fails the build if any locale drops the full surname or if a wrong form reappears anywhere in the tree. The short form "Dr. Non" / "ดร.นน" is fine on its own; a surname, when it appears, is the full one. See CLAUDE.md § "The author's name".

**The brand mark is artwork, and it is derived.** The footer used to carry a black square with "SL" set in it — a placeholder for a mark the site did not have. It now carries the real SLIC Index wordmark, keyed off its paper so it sits on the cream with no plate of its own. The masthead still renders the brand as live type; the two surfaces have different rules and both are gated. `public/Logos/slic-index-mark.png` is **generated** — do not hand-edit it. Run `python3 scripts/build-brand-mark.py`; it writes the PNG and `scripts/brand-mark.provenance.json`, and the integrity gate checks the PNG's transparency, its match to the built copy, and both SHA-256 hashes. See CLAUDE.md § "Branding".

**The supporter row is one line, and every mark in it is keyed.** The footer carries six marks — RCAD (รวพ.), depa, Smart City Thailand Office, ReTL, Axiom and SLIC — in a single line with no boxes, no per-logo frames, and no white plates. UWN (บพท.) is out: it is a unit inside RCAD now, and the roster names the agency. The marks are generated: sources in `logo-sources/logos/`, transparent PNGs in `public/Logos/`, produced by `scripts/build-partner-logos.sh`. A mark that still carries its paper shows a rectangle on the cream. The row must never wrap. All of it is gated. See CLAUDE.md § "Branding".
