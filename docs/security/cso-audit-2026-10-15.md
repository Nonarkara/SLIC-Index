# Security probe: 2026-10-15

Scope: source, local Express, Cloudflare preview and production, dependency lock,
reachable local Git history, and CI configuration. Codex performed the server and
deployment probes; a fresh agent reviewed frontend boundaries and attempted to
break the new edge handler. Tests use synthetic data, never real visitor records.

Result: five confirmed gaps corrected. This is a bounded engineering audit, not
a guarantee that the system is airtight. Database policies and third-party storage
access were not inspected. Owners for the fixes and remaining checks: maintainers.

## Audit coverage

1. Secrets archaeology: Gitleaks scanned reachable local history with redaction.
   Five matches were copies of the same published DHIS2 default-credential tutorial
   example, including generated bundles. No actual credential confirmed. This does
   not cover deleted/unreachable objects, other repositories, or provider accounts.
2. Dependencies: npm audit returned zero advisories for the lockfile, including a
   production-only audit. No claim about unknown vulnerabilities or maintainer trust.
3. CI/CD: actions use commit pins; workflow tokens have scoped permissions;
   Dependabot and high-severity npm audit checks exist. Semgrep/Trivy are explicitly
   report-only; scanner failure can yield an empty report. Treat these summaries as
   advisory, not deployment approval. Provider branch protection was not verified.
4. LLM security: the knowledge rack retrieves static local passages. No production
   model API or agent execution path found in the reviewed application code.
5. Skill supply chain: no runtime loading of agent skills found. Development-agent
   tooling and machine-wide permissions are outside this application audit.
6. OWASP and STRIDE: coverage below. No confirmed DOM XSS, prototype pollution, or
   attacker-controlled external redirect in the inspected frontend paths.
7. Trend: prior hardening on 2026-10-02 passed local tests but missed independent
   edge behavior and same-origin PDF framing. This run adds edge and real-bootstrap
   regressions. No previous formal CSO report exists here for a comparable score.
