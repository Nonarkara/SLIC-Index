## Option A: Digital Solutions (Recommended)

### Short Description (700 chars max — current: ~620)

Most city rankings are marketing. They impute missing numbers, weight GDP above habitability, and accept money to feature cities that can afford the listing fee. SLIC Index V3 works differently. Its scoring engine — an Adjusted Mazziotta–Pareto Index — penalises imbalance: a city that excels in one dimension but is hollow in others falls accordingly. Every score links to a public source URL. A live "Zero-Sum Allocator" lets any reader reassign five pillar weights and watch all 163 cities re-rank in real time. Available in five languages. Built to be read by citizens, not sold to mayors.

### Extended Description (1200 chars max — current: ~1150)

The question behind SLIC is straightforward: what does a city actually cost to live in? Not the brochure version. The median salary, the commute time, the air quality at ground level, the likelihood of being robbed on the street. Twenty-two metrics across five pillars — Growth, Viability, Capability, Community, Creative — drawn from the World Bank, IMF, WHO, UNODC, IQAir, Freedom House, and Numbeo. An absolute scoring engine that never imputes missing data: cities cannot improve their score by simply not reporting the bad numbers.

The "Zero-Sum Allocator" sits at the centre of the experience. Drag one pillar up; the other four contract proportionally. Change the weights; the ranking rebuilds instantly, all 163 cities shuffling to reflect what the user personally believes a liveable city should prioritise. This makes the model's assumptions visible — the only honest way to present a ranking.

No rounded corners. No gradients. Hairline borders and mono numerics against a cream background. Five languages — each script in its non-looped, native-register form. Backed by DEPA and PMU-A, Thailand's national digital-economy and area-based development agencies. No paid placements. No imputed data. Every number links to its source.

## Option B: Interface & User Experience Design

### Short Description (700 chars max — current: ~610)

City data is dense, political, and usually hidden behind a paywall. SLIC Index V3 makes it navigable. Every design decision points in one direction: make the methodology more auditable, not less. Hairline borders and mono numerics let the data breathe. The "Zero-Sum Allocator" — a live, draggable spider chart — teaches the zero-sum logic of urban policy before the user reads a single line of methodology text. 163 cities ranked across five pillars, available in five languages, no paid placement, no imputed data. A ranking you can argue with.

### Extended Description (1200 chars max — current: ~1100)

A city ranking has exactly one honest form: one you can disagree with.

The core interaction of SLIC Index V3 — the "Zero-Sum Allocator" — is a five-axis spider chart the user controls. Drag one pillar up; the other four contract. The 163-city board rebuilds beneath it without a page load. The tool is not decoration: it forces every user to commit to a set of values before they see the result. A user who weighs safety most assigns more weight to Community. A user focused on economic mobility weights Growth. What emerges is not a universal truth but a transparent instrument.

The design system enforces this legibility. Three typefaces, three text sizes — Libre Baskerville for display, Inter for body, JetBrains Mono for data values and source labels. Cream background (#f8f5f0), dark navy text (#1c1914), a single amber accent (#b85c28). No gradients. No rounded corners. Typography in five languages — each script specified in its non-looped native form: IBM Plex Sans Thai rather than the looped alternatives that read as "learner material" to native readers.

The result is not a dashboard. It is a public argument about what a city is worth.
