>
> **[0:52 — Bangkok scorecard, Alpha slot highlighted]**
>

>
> **[1:08 — the methodology PDF spread on screen]**
>
> If you don't trust the result, audit the math. The methodology paper, the city CSV, the source code — all public. In English, Thai, and Chinese.
>
> **[1:18 — final shot, the URL]**
>
> SLIC dot nonarkara dot org. Smart and Liveable Cities Index. Built in Thailand. For anyone who wants to read a city ranking as a publication, not a press release.

## Direction notes for the recording session

- **Audio:** voice should be unhurried — Wong Kar-wai cadence (§14 visual DNA rule #7), not investor-pitch energy. Pauses are allowed after the provocation lines.
- **Visuals to capture before recording day:**
  1. The homepage scroll from hero → Alpha tier band
  2. A finger or cursor dragging the spider allocator pillar weights
  3. A side-by-side Compare page comparison (SLIC vs EIU and Monocle, showing Bangkok / London / Singapore positions diverging)
  4. Bangkok city scorecard at Alpha slot 10
  5. Methodology PDF cover (after Pass 3 PDF refresh lands)
  6. The CSV header block opening in a spreadsheet, showing the metadata top rows
- **B-roll** (optional): GITEX Singapore 2026 main stage shots if any are usable; Bangkok ambient footage; one ground-level Bangkok street shot.
- **Type-on-screen rule:** any text overlay uses the same three-size hierarchy as the site (display / body / mono micro). No new typeface. No drop shadow.
- **End frame:** logo + URL on cream `#f8f5f0` background, three-second hold. The juror's last impression should be the brand lockup at rest.
