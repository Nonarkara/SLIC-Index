## PROJECT DETAILS

### Project Title
```
SLIC Index: An Open-Source, Transparent Alternative to Establishment City Rankings
```

### Project Abstract
```
The Smart and Liveable Cities Index (SLIC) is an open-source city ranking system that challenges establishment indices (EIU, Mercer, Monocle, Resonance, Yonsei-Cambridge) by measuring what actually matters to residents — not expats, tourists, or investors.

Unlike proprietary rankings that use opaque methodologies to calculate corporate hardship allowances, SLIC measures disposable income after rent (PPP-adjusted), working-time pressure, tolerance and civic openness, cultural experience diversity, suicide and mental strain, and graduate housing burden — dimensions no other major index covers.

Key features:
• 157 cities ranked across 5 pillars and 35 verified signals
• Every score traces back to its public data source — no proprietary black boxes
• Interactive weight allocation: users can drag a spider diagram to rebuild the ranking based on their own priorities
• Coverage transparency: war-zone cities and data-sparse regions are placed on a watchlist rather than quietly dropped
• Multilingual: English, Thai, Chinese

The project has been presented at the Smart City Summit & Expo (SCSE) 2026 in Taipei to 3,000+ professionals, where a European mayor's alliance requested to adopt it as an alternative to The Economist Intelligence Unit's Global Liveability Index.

Three versions document the evolution from a LinkedIn provocation (V1, 103 cities) to an interactive platform (V2, 174 cities, Taipei launch) to an editorial op-ed with six-index comparative analysis (V3, 157 ranked cities with watchlist transparency).

All code, data, and methodology are publicly available on GitHub.
```

## RESEARCH ITEMS TO ADD

### Item 1: SLIC Index V3 — Software
**Type:** Software / Code
**Title:** SLIC Index V3: An Interactive, Open-Source City Ranking Platform
**Description:**
```
Open-source web application that ranks 157 cities across 5 dimensions of liveability using 35 verified signals from public data sources (World Bank, WHO, ILO, OECD, UNESCO, OpenAQ, Copernicus).

Unlike establishment indices that use proprietary methodologies, SLIC publishes every data point, every formula, and every coverage grade. Users can interactively reweight the five pillars (Growth, Viability, Capability, Community, Creative) using a drag-based spider diagram and watch 157 cities re-rank in real time.

The platform includes a six-index comparative analysis showing how SLIC's top 10 differs from EIU, Mercer, Resonance, Monocle, and the Yonsei-Cambridge Smart Cities Index — and what each index's blind spots are.

Built with React 19, TypeScript, Vite. Deployed on GitHub Pages (free, public).
```
**DOI/URL:** https://github.com/Nonarkara/SLIC-Index
**Keywords:** smart cities, city ranking, open source, data visualization, urban analytics, liveability

## TIPS FOR MAXIMUM RESEARCHGATE ENGAGEMENT

Based on research (sources: [ResearchGate Help](https://help.researchgate.net/research-and-publications/research-spotlights), [SciTechEdit tips](https://scitechedit.com/optimizing-your-researchgate-profile/)):

1. **Use Research Spotlights** — this is the #1 growth tool. ResearchGate's algorithm shows Spotlights to researchers in your field. Create one immediately after adding the project.

2. **Add all keywords** — each keyword connects you to a different research community. Use ALL the keywords listed above.

3. **Upload the methodology PDF** — PDFs get far more reads than links. If you have the SLIC methodology paper as a PDF, upload it as a separate research item.

4. **Post weekly updates** — each update triggers notifications to followers and project watchers. Post updates about new cities added, methodology refinements, conference presentations.

5. **Ask a question** — ResearchGate Q&A gets high engagement. Post: "What metrics should a city ranking prioritize if the goal is measuring liveability for residents rather than expats?"

6. **Endorse collaborators** — endorse Assoc. Prof. Poon's skills, request endorsements back.

7. **Link to other publications** — if you or Poon have published papers on smart cities, link them as "Related research" in the project.

8. **Respond to every comment** — ResearchGate rewards engagement. Reply to everyone who interacts.

9. **Complete your profile** — full bio, education, institutional affiliation, photo, all publications.

10. **Cross-post to LinkedIn** with a link back to the ResearchGate project page — drives traffic both ways.
